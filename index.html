How this works: a plain website cannot read cross-origin profile pages directly. X/Twitter is fetched directly (works today). The other four go through a fallback chain of public CORS proxies, which you do not control.
  • X — direct fetch, reliable today, fragile if X changes its CORS policy.
  • YouTube — proxy + HTML parsing, usually accurate.
  • Instagram / Facebook — proxy + parsing, frequently blocked by login walls → often uncertain.
  • TikTok — every profile returns HTTP 200, so a “found” signal is not trustworthy → often uncertain.
